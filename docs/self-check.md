## 3. 发现并修复的问题

### 3.1 移动端操作按钮横向溢出

**现象：** 390px 宽度下首页两个 Hero 按钮保持横排，第二个按钮被裁切。  
**修复：** 小屏改为单列按钮，并给标题和内容容器增加最小宽度与换行约束。  
**回归：** 390px 页面宽度 `scrollWidth = 390`，无越界元素。

### 3.2 不同报警码证据混入

**现象：** 查询 E201 时，同设备的 E203 工单仍可能进入证据包，降低解释准确性。  
**修复：** 当查询出现已知报警码时，只保留同码 SOP 和同码历史案例，再执行排序。  
**回归：** E201 结果只包含 `KB-AC-001` 与 `CASE-001`。

### 3.3 复合安全描述绕过

**现象：** “拆开正在运行的风机护罩”没有采用固定短语命中旋转设备规则。  
**修复：** 增加“拆/打开 + 护罩 + 运行/运转”的复合条件。  
**回归：** 触发 `SAFE-ROTATING`，只输出停机和隔离步骤。

### 3.4 高危结论未优先引用安全规程

**现象：** 带压拆管请求触发了安全门，但通用 LOTO 规程可能因证据数量限制而未出现在前五条参考中。  
**修复：** 安全门触发时强制把 `KB-GEN-001` 放到证据首位，并增加“安全门槛优先引用”理由。  
**回归：** 带压拆管请求的首条证据为通用能量隔离规程。

### 3.5 通用设备别名误识别

**现象：** 搜索 `AC-02` 时，第一台空压机的通用别名可能先命中，导致资产识别为 AC-01。  
**修复：** 显式设备编号优先；通用别名命中多个设备时返回“未确定”，不任意选择。  
**回归：** `AC-02` 正确识别为 AC-02；仅输入“空压机”不猜测具体编号。

### 3.6 报警码子串误匹配

**现象：** 简单包含判断可能把 `E2010` 识别成 `E201`。  
**修复：** 使用前后边界约束和可选连字符的正则匹配。  
**回归：** `E201` 命中，`E2010` 不命中。

### 3.7 重复审批并发风险

**现象：** 先读取状态再更新存在两个审批人同时通过的风险。  
**修复：** SQLite 更新语句增加 `WHERE status = 'pending_approval'`，并检查受影响行数。  
**回归：** 重复审批返回“不可审批”或“已被其他审批人处理”。

### 3.8 Windows PowerShell 启动失败

**现象：** PowerShell 5.1 将无 BOM 的 UTF-8 中文脚本按本地代码页读取，造成字符串截断和解析错误。  
**修复：** 启动脚本全部改为 ASCII，页面和业务数据仍使用 UTF-8。  
**回归：** 使用 Windows PowerShell 5.1 成功启动便携运行时和服务。

### 3.9 浏览器产生 favicon 404

**现象：** 页面未声明图标，浏览器请求 `/favicon.ico` 产生控制台错误。  
**修复：** 增加本地 SVG favicon 和显式 link。  
**回归：** 浏览器完整流程控制台无错误。

### 3.10 静态资源不支持 HEAD

**现象：** 健康检查正常，但 `HEAD /` 返回 501。  
**修复：** 为静态资源增加只返回响应头的 HEAD 处理；API 明确返回 405。  
**回归：** `HEAD /` 返回 200。

## 8. 仍存在的风险

### 生产身份与权限

演示版没有真实登录和角色校验。生产环境必须接入 SSO，并在服务端验证“谁可以查看哪台设备、哪份文档、审批哪类工单”。

### 安全规则覆盖有限

当前规则用于证明技术路线，只覆盖演示场景的常见风险。真实部署必须结合企业危险源清单、作业许可制度、设备厂商规程和工业安全专家评审。

### 数据质量

当前设备、SOP 和工单全部为合成数据。真实试点需要验证文档版本、测量单位、人员表述差异、报警码映射和历史工单质量。

### 小规模检索引擎

BM25 适合当前离线原型，但大规模知识库需要文档切分、版本过滤、权限过滤、向量混合检索和增量索引。

### Docker 未实际构建

当前机器没有 Docker。`Dockerfile` 已完成静态检查，但尚未在本机执行镜像构建；Windows 便携版本已经实际启动并验证。

### 人工审批不能等同于安全认证

系统记录“谁批准了什么”，但不能替代现场 LOTO、工作票、设备隔离和授权人员复核。
